versions, and DOI values from `../manifests/sources.json` in publications and
distributed derived artifacts.

The Kaggle API labels ASL Alphabet as `GPL 2`. Before distributing a trained
model or bundled derivative, review the GPL 2 obligations for that artifact.

Dataset licenses do not replace consent, privacy, or model-card documentation.
The application should continue to process camera frames locally and should not
store or upload user images without explicit consent.
